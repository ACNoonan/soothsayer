# soothsayer-verify

Run your own Soothsayer verifier.

Soothsayer publishes calibrated fair-value bands and claims they achieve
their target coverage (`τ`). This CLI lets anyone check that claim
**without trusting any Soothsayer infrastructure**: it reads the public
band archive (claims only — the archive contains no realised prices),
fetches the realised Monday opens itself from Yahoo, and recomputes the
coverage statistics with its own implementations.

```
cargo run --release -p soothsayer-verify -- coverage
```

## Trust model

| Tier | Command | What it proves |
|---|---|---|
| T1 | `coverage` | The archived bands covered independently-fetched opens at the claimed rate (Kupiec, Christoffersen, per-symbol) |
| T2 | `receipt`, `artefact` | The on-chain `PriceUpdate` decodes and holds its invariants; the frozen artefact's canonical self-hash and parquet hash reproduce the stamps the archive rows name |
| T3 | (not yet built) | Re-derive the bands themselves from the frozen scalars + public market data |

Independence guarantees baked in:

- **The statistics are re-implemented, not imported.** If this tool
  reused the Python `metrics.py` the reports are built with, a bug there
  would self-confirm. The Rust implementations are parity-pinned against
  scipy to ≤1e-9 (`tests/parity.rs`, fixture generated by
  `scripts/gen_verify_parity_fixture.py`), including the real
  forward-tape panel.
- **Truth is fetched by the verifier at run time** (Yahoo v8 chart daily
  opens — the same source/convention the evaluation panel uses). The
  archive deliberately carries no truth column.
- **The audit chain closes on hashes.** Archive rows name the frozen
  artefact's SHA-256; `artefact` recomputes it from the canonical JSON
  and checks the frozen parquet beside it.

## Commands

```bash
# Full coverage audit (defaults to the public archive on GitHub):
soothsayer-verify coverage
soothsayer-verify coverage --archive data/band_archive/bands_v1.csv   # local checkout
soothsayer-verify coverage --tau 0.95 --symbol SPY --since 2026-06-01 --json

# Decode a live on-chain PriceUpdate and check its invariants:
soothsayer-verify receipt --account <PUBKEY> --url devnet

# Verify a frozen artefact's self-hash + parquet hash + archive linkage:
soothsayer-verify artefact \
  --file data/processed/lwc_artefact_v1_frozen_20260504.json \
  --archive data/band_archive/bands_v1.csv
```

Exit codes: `0` = claims consistent / hashes verified; `1` = a pooled
Kupiec test rejects a coverage claim at the 5% level, an invariant
fails, or a hash mismatches; `2` = data or network error.

## Caveats the output also prints

- **Provenance.** Archive rows are labelled. `retro_frozen` rows were
  computed after the weekend outcome from an artefact frozen *before*
  it (the freeze hash is the pre-registration); `published_pre_open`
  rows (future) are emitted before the outcome exists.
- **Truth can be revised upstream.** Yahoo occasionally revises open
  prints. Live example: AAPL's 2026-07-06 open sat 4.6 bps inside the
  τ=0.68 band edge as captured near that Monday, and later revised to
  just outside it — realised coverage at τ=0.68 differs by one row
  (33 → 34 violations of 120) from the capture-time report, with no
  verdict change. A ±1-row delta on band-edge-marginal rows is expected
  behaviour of an independent audit, not a bug.
- **Splits.** Bands are recorded on the as-traded scale of their
  weekend; Yahoo rescales history after splits. The verifier
  renormalises using Yahoo's own split events and discloses every
  adjustment it makes.
- **Rate limits.** Yahoo 429s bursty anonymous clients; the verifier
  paces requests and retries with backoff. Repeated back-to-back runs
  may still get throttled — wait a minute.
- **Scope.** T1 audits coverage of the recorded bands. It does not
  re-derive the bands from market data (T3) and cannot attest *when* a
  `retro_frozen` band was computed — that is exactly what the archive's
  provenance column and, eventually, on-chain `publish_ts` are for.

## Note on repo hard rule #1

Soothsayer's analysis code never fetches upstream data (everything goes
through scryer). This crate is the sanctioned, scoped exception: a
verifier that read its truth from Soothsayer's own data plumbing would
be circular. Nothing under `src/soothsayer/` or `scripts/` may call
into this crate for analysis.
